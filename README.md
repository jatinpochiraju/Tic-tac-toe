**Tic-Tac-Toe** is a classic two-player game implemented in both C and HTML. This project allows players to engage in the timeless game of Tic-Tac-Toe through a simple and intuitive interface.

## Features

- Play the traditional 3x3 Tic-Tac-Toe game.
- Two-player mode for head-to-head matches.
- Implemented in both C (`tic_tac_toe.c`) and HTML (`tic_tac_toe.html`).
- Includes a visual representation of the game board (`Tic-Tac-Toe.png`).

## Getting Started

### HTML Version

1. Open `tic_tac_toe.html` in your preferred web browser.
2. Follow the on-screen instructions to start playing.

### C Version

1. Compile the C source code:

   gcc tic_tac_toe.c -o tic_tac_toe

2. Run the compiled program:

   ./tic_tac_toe

3. Follow the console prompts to play the game.

## Project Structure

- `tic_tac_toe.c` - C source code for the game.
- `tic_tac_toe.html` - HTML version of the game.
- `Tic-Tac-Toe.png` - Image representing the game board.
- `Website/` - Directory containing website assets and additional resources.
